장면 분석

새 분석을 위한 실행 안내

  1. ZIP 압축을 모두 푼 뒤 run_windows.bat을 실행하세요. 설치와 서버 실행이 끝날 때까지 검은 창을 닫지 마세요.
  2. 로컬 분석 화면 열기 ↗를 누르세요. 주소창이 file:///…/index.html이면 저장 결과 보기 모드입니다.
  3. Ollama를 켜고 ollama pull qwen3-vl:2b로 모델을 설치한 뒤, 로컬 화면에서 ‘이 영상 분석하기’를 누르세요.

macOS/Linux: bash run_local.sh 실행. 다른 모델 연결 방식은 README.md를 참고하세요. HTML 파일만으로는 새 AI 분석을 실행할 수 없습니다.

저장된 결과를 바로 볼 수 있습니다. 새 분석은 로컬 서버와 모델 연결이 필요합니다.
