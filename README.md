# AICAFE Scene Lab 0.1

공개 CCTV 영상에서 **사람 출입·이동 / 물건 운반·인계 / 차량 상하차**를 설명하고 사람이 검토하는 첫 번째 실행 버전입니다. 공장 전용 인식기나 학습 완료 제품은 아닙니다. 확보 가능한 MEVA 영상으로 모델의 관찰 능력부터 검증합니다.

## Codex 클라우드에서 이어서 개발

클라우드 연결 절차와 첫 작업 지시는 `CLOUD_HANDOFF.md`에 있습니다. 기본 설치는 `bash scripts/setup_cloud.sh`, 이후 검증은 `bash scripts/check_cloud.sh`입니다. 기본 설치에는 모델 가중치와 GPU가 필요하지 않습니다. 저장소: https://github.com/leemask/aicafe-scene-vlm . Codex 환경 생성·게시는 별도 단계입니다.

## 기존 PC에 분석 결과 적용하기

이 ZIP을 **기존 설치 폴더와 다른 폴더**에 압축을 푼 뒤, 그 안의 `apply_analysis_update.cmd`를 실행하세요. 대상은 `C:\Users\andre\Downloads\aicafe-scene-vlm`입니다. 기존 화면·샘플 파일을 백업하고 `web/`, `samples/`를 교체하며 새 `qwen-full-*` 분석 결과와 근거 프레임, 보고서를 추가합니다. 이미 존재하는 결과 파일은 덮어쓰지 않으며 `data/`의 업로드는 건드리지 않습니다. 적용 후 브라우저에서 Ctrl+F5를 누르고 원하는 영상을 선택하면 저장된 분석과 근거 프레임을 볼 수 있습니다. Windows 실행은 이 개발 환경에서 실측하지 못했습니다.

## 바로 보기

압축을 풀고 `index.html`을 브라우저로 여세요. 서버나 API 키 없이 64개 영상 모두의 실제 Qwen VLM 출력을 볼 수 있습니다. 이전 결과 9개도 보존했으며, 화면에는 최신 전체 분석을 우선 표시합니다. 분석 완료는 내용이 정확하다는 뜻이 아닙니다. 주요 오인식과 영상별 요약은 `ANALYSIS_REPORT.md`에 정리했습니다. 검색은 설명·모델 원문·행동 이름의 문자열 검색입니다. 의미 임베딩 검색은 아직 없습니다.

- 영상을 선택하고 재생합니다.
- 설명과 근거 프레임, 원문을 대조합니다.
- 검토 결과와 메모를 저장하고 JSON으로 내보냅니다.
- 오프라인 검토는 해당 브라우저의 저장소에만 남습니다. 별도 보관하려면 내보내세요.

## ‘이 영상 분석하기’가 비활성화된 경우

이전 버전에서 HTML을 직접 열면 새 분석 버튼이 설명 없이 비활성화됐습니다. 수정 버전에서는 ‘분석 실행 안내’ 버튼과 실행 절차를 표시합니다. 이미 다운로드한 ZIP은 자동 업데이트되지 않으므로 수정본을 다시 받아 별도 폴더에 압축을 풀어 주세요.

1. `run_windows.bat`을 실행하고 설치가 끝난 뒤 서버 창을 열어 둡니다.
2. 브라우저 주소창에 `http://127.0.0.1:8000`을 입력합니다. `file:///` 주소에서는 새 분석을 실행할 수 없습니다.
3. Ollama 실행 및 `ollama pull qwen3-vl:2b` 설치를 완료하고 기본 연결 방식을 사용합니다. 다른 연결 방식의 준비는 아래를 참고하세요.
4. 서버 주소에서도 ‘서버 미연결’이 표시되면 서버 창의 오류를 확인하고 ‘서버 연결 다시 확인’을 누릅니다.

## 내 영상 분석하기

Python 3.11 또는 3.12를 권장합니다. Windows는 `run_windows.bat`, macOS/Linux는 `bash run_local.sh`를 실행하고 http://127.0.0.1:8000 에 접속합니다. 최초 실행은 인터넷으로 의존성을 설치합니다. 서버는 본인 PC의 localhost에만 엽니다.

기본 설치만으로는 VLM 모델이 설치되지 않습니다. 아래 중 한 가지를 준비하세요.

### 로컬 Ollama

Ollama 0.12.7 이상을 설치한 뒤 `ollama pull qwen3-vl:2b`를 실행하고 Ollama를 켠 상태에서 앱의 ‘로컬 Ollama’를 선택합니다. 이 어댑터는 모의 HTTP 응답으로 테스트했으며 이번 배포의 실측은 아래 직접 실행 방식입니다. 공식 모델 안내: https://ollama.com/library/qwen3-vl:2b

### Qwen 직접 실행

서버를 종료한 뒤 해당 가상환경에 `requirements-local-model.txt`를 추가 설치하고 다시 서버를 켭니다.

Windows:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-local-model.txt
.\run_windows.bat
```

macOS/Linux:

```bash
.venv/bin/python -m pip install -r requirements-local-model.txt
bash run_local.sh
```

앱에서 ‘로컬 Qwen3-VL · 직접 실행’을 선택합니다. 모델 이름은 고정입니다. 기본은 Hugging Face에서 약 4.3GB 가중치를 다운로드하며, 다운로드한 폴더가 있으면 서버 시작 전 `QWEN_VLM_PATH`를 지정할 수 있습니다. 현재 직접 실행은 CPU 구현입니다. 실제 사용 메모리는 가중치 크기보다 큽니다. GPU 자동 선택·양자화·스트리밍은 구현하지 않았습니다.

### OpenAI API (선택)

서버 환경변수 `OPENAI_API_KEY`를 설정하고 서버를 다시 켭니다. 앱에서 OpenAI 연결과 프레임 전송 옵션을 선택해야 호출합니다. 이 경우 샘플 프레임이 외부 API로 전송되고 사용료가 발생할 수 있습니다. 키를 브라우저나 코드에 입력하지 않습니다. 이 연결의 실제 API 호출 검증은 하지 않았습니다.

## 현재 범위

- 최대 250MB, 10분 이하 업로드. 브라우저 재생용 MP4로 변환하고 오디오를 제거합니다.
- UI에서 새 분석은 기본 10초 창, 창당 4개 프레임, 처음 12개 창(최대 2분). 분석한 범위를 화면에 표시합니다.
- 동시 분석 작업 1개. 모델 로딩과 CPU 추론에 시간이 걸립니다. 실행 중 서버를 종료하면 작업은 중단으로 기록합니다.
- 모델 출력의 잘못된 JSON은 판단 보류로 보존합니다. 실패한 호출을 성공 결과로 바꾸지 않습니다.
- 분석·검토 결과는 `results/`, 업로드 영상은 `data/`에 저장됩니다. 웹 UI에서 삭제하는 기능은 아직 없습니다.
- 탐지·추적기, 거리 측정, 실시간 RTSP, 자동 알림, 재학습은 아직 없습니다. 행동 카테고리는 모델의 추정입니다.
- VLM에 정답 주석·파일명·원본 경로를 전달하지 않습니다. 프레임과 상대 시각, 공통 지시문만 사용합니다.

## 이번 전체 분석

- 모델: Qwen/Qwen3-VL-2B-Instruct, CPU, 8스레드, 배치 4개.
- 입력: 영상당 시간순 프레임 3개(12초 영상은 2·6·10초, 20초 영상은 약 3.33·10·16.67초), 최대 576×324.
- 화면의 ‘배치 평균’ 시간은 배치 추론 시간을 포함 영상 수로 나눈 값으로 단일 영상 지연시간과 다릅니다.
- 정답 주석과 파일명은 모델에 전달하지 않았습니다. 없는 사람·자전거 묘사 등 오류가 있어 원문과 프레임을 함께 검토해야 합니다.
- 프레임 대조 메모는 ChatGPT의 일부 프레임 검토이며 사람의 정답 라벨이 아닙니다. 사용자 검토 상태는 모두 검토 대기로 둡니다.
- `python scripts/analyze_all.py --batch-size 4 --threads 8`로 재현할 수 있습니다. 설치와 모델 준비는 위 안내를 따릅니다. 기존 전체 분석 결과가 있으면 해당 영상은 건너뜁니다.

## 데이터와 학습의 다음 단계

64개 클립은 12개 원본·12대 카메라에서 뽑은 총 1,024초(17분 4초)입니다. 기존 32개는 12초씩이며 일부 창이 겹칩니다. 추가 32개는 20초씩이며 같은 원본 안에서 서로 겹치지 않습니다. 모든 영상은 하나의 MEVA 시설에서 촬영한 것으로, 공장 현장 데이터나 서로 다른 12개 사업장은 아닙니다. 같은 원본의 인접 창을 학습·평가로 나눠 성능을 부풀리지 않도록 `split_group`을 기록했습니다. 공개 부분 주석이 없는 구간을 음성 정답으로 취급하지 않습니다.

우선 클립별 사람이 보이는 행동·가림·작은 물체·모델 오류를 검토하세요. 이후 별도 카메라의 영상과 실제 사업장 영상을 확보해 현장별로 분리한 평가셋을 만듭니다. 이 배포에서는 추가 학습 없이 기존 VLM을 실행했습니다. 검토 데이터를 충분히 모은 뒤 미세조정 여부를 판단할 수 있습니다.

## 개발·재현

```bash
python -m unittest discover -s tests -v
python scripts/batch_qwen.py
python scripts/build_bundle.py
```

`batch_qwen.py`는 제공 영상당 3개 프레임(2·6·10초)을 사용하며 UI의 새 분석 기본값과 다릅니다. 기존 `qwen-*.json`이 있으면 건너뜁니다. 새 평가 전에는 결과를 별도 폴더로 보관하고 재실행하세요. 실측 조건과 한계는 `VERIFICATION.md`를 참고하세요.

기존 32개 재생성은 `scripts/download_sources.py --research PATH`와 `scripts/prepare_samples.py --research PATH`를 사용합니다. 추가 32개는 `scripts/expand_samples.py --work PATH`로 재생성하며 신규 원본 다운로드가 필요합니다. 완성된 배포 ZIP에는 12초·20초 클립이 이미 들어 있어 원본을 다시 받을 필요가 없습니다.
